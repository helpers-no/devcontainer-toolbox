# Active plans

At most one or two `PLAN-*.md` files live here while they are being implemented.

When nothing is in progress, say so on this page (do not leave the folder empty of a readable
file — Docusaurus needs a doc). Point at [`../backlog/1PRIORITY.md`](../backlog/1PRIORITY.md)
for what would be next.

INVESTIGATE files never live here — see [PLANS.md](../../PLANS.md).
